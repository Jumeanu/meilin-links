# MEILIN · 美琳 — Links

หน้ารวมลิงก์ของ MEILIN — เลานจ์บาร์เซี่ยงไฮ้ยามดึกแบบพิกเซลอาร์ต  
Link page for MEILIN — a late-night Shanghai lounge in pixel art.

## เว็บในโปรเจกต์ / Projects

- `what-to-drink/` — WHAT TO DRINK BAR · ควิซ "วันนี้ดื่มอะไรดี?" ในบาร์พิกเซล  
  A "What should I drink tonight?" quiz in a pixel bar.
- `puifai-petspa/` — ปุยฝ้าย เพ็ทสปา · เดโมระบบจองคิวร้านอาบน้ำตัดขนสัตว์ (ร้านสมมติ) มีปุ่ม TH/EN  
  Puifai Pet Spa — a booking-system demo for a fictional pet grooming shop, in Thai and English.
- `hearth-bakery/` — HEARTH BAKEHOUSE · เบเกอรี่พรีออเดอร์ ออกแบบขนมได้เอง (ร้านสมมติ) มีปุ่ม TH/EN  
  Hearth Bakehouse — a pre-order bakery demo where customers build their own bake step by step, in Thai and English.  
  Built output of [Jumeanu/Hearth_Bakery](https://github.com/Jumeanu/Hearth_Bakery) (`npm run build:public`).
